# Social Sentiment Report

## Overview of the language used
> For this assignment, the language JavaScript was used to build a sentiment analysis tool that reads a sentiment table and analyzes test files to produce an overall sentiment score based on the words in those files. Since JavaScript is primarily a browser-compatible language, this assignment was completed using Node.js, a server-side runtime that allows JavaScript to run outside of the browser. By using Node.js, the program was able to interact with the file system and process data directly in the terminal, eliminating the need for any HTML files or a browser interface. This made it possible to leverage JavaScript for backend tasks such as reading files, parsing text, and computing sentiment scores efficiently.

## Approach
> The approach used to find complete this assignment was to tackle each subprogram on at a time to see the limitations and the advantages of using this language for an assignment like this. The fist task was to be abel to read the socialsent.csv file. Since this assignment was completed using the framwork node.js this meant having to import the node.js's fs in order to be able to use the readfile method and access the data inside of the file. Since the readfile method converts the data from the file into one huge string the next step involved parsing that string into more managble chunks of data. The string was then split into lines so every new space character we would splice the string and store it into an array which left us with an array of strings.From here we iterated though the array and split every string where a comma was encoutered which left us with a tuple of a word and a value. These word and value tuples were then inserted into a Java Script object which served as dictionry where the word would be a key and the value associated was the score of the word. From here the next subprogram would gather the filename from the user via terminal input and from the file is found and read as one string. The string is then split on every word and converted to lowercase so that it matches with the social sentement table. If the word in the string is found in the sentement table then the score is retrived and added to a grand total for the file, giving us the sentiment score. The number of stars is calculated by using a switch statement and seeing where the total score falls in with respect to the number of stars.
