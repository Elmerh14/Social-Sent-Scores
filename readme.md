# Social Sentiment Score Analyzer

This Node.js program analyzes the sentiment of a review by calculating a total sentiment score using a predefined sentiment dictionary (CSV format). It outputs a star rating (1–5 stars) based on the computed score.



## Getting Started

### 1. **Prerequisites**

- Node.js (version 18 or later recommended for native `fs/promises` support)
- A sentiment CSV file (e.g., `socialsent.csv`)
- A review text file (e.g., `review.txt`)

### 2. **Installation**

in your terminal run **npm-init** to create a package.json

### Execution Instruction
To run the program type **node index.js** in your terminal. This will analyze the default file **review.txt**

To analyze a specific file ex: good.txt:
Run **node index.js good.txt**
